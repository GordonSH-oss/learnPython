# 安全和可观测性

生产代码要能保护用户数据，也要能解释自己出了什么问题。安全和可观测性应该从学习阶段就进入示例，而不是上线前才补。

## 学习目标

- 不把 API key、token、密码写进代码或日志。
- 对 URL、文件路径、用户输入做边界校验。
- 用结构化日志记录操作、耗时和错误原因。
- 理解健康检查、指标、trace id、日志脱敏的作用。

## 本目录文件

- `logging_security.py`：演示日志脱敏、URL 校验和错误日志边界。

## 练习

1. 给日志增加 `request_id` 字段。
2. 增加一个对本地私有 IP 的 URL 拦截规则。
3. 把 `print` 全部换成 logger，并统一日志格式。
