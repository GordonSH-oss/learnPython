# 线性代数如何驱动神经网络

## 学习目标

学完本章后，你应能根据输入和权重的形状判断一层网络是否合法，并解释前向传播、损失和梯度下降之间的关系。

## 1. 从样本到批次

一个样本通常表示为向量 $x \in R^d$。把 $n$ 个样本按行堆叠，得到批次矩阵 $X \in R^{n \times d}$。图像和序列保留额外维度，但进入全连接层前仍要明确“批次维”和“特征维”。

## 2. 线性层

线性层计算：

$$Y = XW + b$$

若 `X.shape == (batch, input_features)`，则 `W.shape` 必须是 `(input_features, output_features)`，输出形状为 `(batch, output_features)`。偏置 `b` 通过广播加到每个样本。

线性层只能表达线性关系。多个线性层之间如果没有激活函数，仍可合并成一个线性变换。ReLU、sigmoid 等非线性函数使网络能拟合更复杂的边界。

## 3. 分类输出与损失

分类器通常输出 logits，而不是直接输出概率。softmax 将每行 logits 转成和为 1 的概率分布。交叉熵衡量模型给真实类别分配的概率是否足够高。

数值稳定的实现会先减去每行最大值，再计算指数，避免较大 logits 导致溢出。

## 4. 梯度下降

损失函数把预测误差压缩成一个标量。梯度描述参数发生微小变化时损失如何变化：

$$\theta \leftarrow \theta - \eta \nabla_\theta L$$

学习率 $\eta$ 太大会震荡或发散，太小则收敛缓慢。反向传播不是另一种优化器，而是高效计算梯度的算法；优化器负责使用梯度更新参数。

## 5. 卷积、序列和 Attention 的共同点

- 卷积通过局部连接和权重共享提取空间模式。
- RNN 在时间步之间传递隐藏状态，共享同一组参数。
- Attention 使用 $QK^T$ 计算相关性，再用 softmax 权重汇总 $V$。

它们最终都由张量变换、矩阵乘法、逐元素运算和归约构成。框架的价值是自动求导、设备执行、批处理和成熟算子的组合，而不是改变这些数学基础。

## 调试直觉

1. 先写出每个张量的语义和形状，再看代码。
2. 损失不下降时，检查数据、目标、梯度和学习率，而不只是增加训练轮数。
3. 分类任务不要在交叉熵之前手动 softmax。
4. 训练指标异常好时，优先排查训练集和验证集是否泄漏。
