2. **中级（41-70）**：函数式编程、异步编程、性能优化
3. **高级（71-100）**：设计模式、系统设计、工程实践

### 按场景学习
- **Web 开发**：题目 31-35, 61-65, 66-70, 91-95
- **数据处理**：题目 36-40, 56-60, 81-85
- **系统设计**：题目 71-75, 96-100
- **性能优化**：题目 16-20, 56-60, 100

### 实践建议
1. 每道题都要自己动手实现
2. 理解原理，不要死记硬背
3. 结合实际项目经验
4. 关注 Python 最新特性
5. 定期复习易错题
