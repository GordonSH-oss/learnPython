# 06 指针

## 学习目标

建立“指针是带类型的地址”这一心智模型，并能安全地解引用、遍历数组和使用输出参数。

```text
变量 value        地址 0x...       内容 42
指针 p            地址 0x...       内容为 value 的地址
*p                                 访问 value 的内容
```

```c
int value = 42;
int *p = &value;
*p = 100;
```

`&value` 取得地址，`*p` 解引用。`int *` 表示它指向的位置应按 `int` 解释。空指针 `NULL` 表示不指向有效对象，解引用空指针是未定义行为。

## 用指针修改调用者数据

```c
bool divide(int a, int b, int *result) {
    if (b == 0 || result == NULL) {
        return false;
    }
    *result = a / b;
    return true;
}
```

返回值表达成功或失败，输出参数携带计算结果。这是常见 C 接口模式。

## 指针算术

若 `p` 指向数组元素，`p + 1` 指向下一个元素，而不是地址简单加 1 字节。步长由所指类型决定。只允许在同一个数组对象及其末尾后一位置范围内计算指针。

## `const` 的方向

- `const int *p`：不能通过 `p` 修改所指整数。
- `int *const p`：`p` 本身不能改指向。
- `const int *const p`：两者都不能改。

## 常见错误

未初始化指针、悬空指针、返回局部变量地址、重复释放和越界指针都可能产生未定义行为。使用前明确回答：它指向什么、对象还活着吗、可访问多少元素、谁负责释放？
