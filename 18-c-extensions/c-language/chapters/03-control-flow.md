# 03 分支与循环

## 学习目标

使用条件和循环表达业务规则，理解循环不变量、边界和退出条件。

## 分支

`if` 适合范围和复合条件，`switch` 适合一个整数或枚举值的离散分支。C 中 `0` 为假，非 `0` 为真。

```c
if (score >= 60) {
    puts("pass");
} else {
    puts("fail");
}
```

不要误写成 `if (score = 60)`，这会赋值。开启编译警告能帮助发现它。

## 循环

- `for`：次数或索引明确。
- `while`：先判断条件，再执行。
- `do ... while`：至少执行一次。

写循环前回答三个问题：状态从哪里开始、什么时候停止、每轮怎样接近停止条件。数组索引通常从 `0` 开始，并满足 `i < length`。

`break` 退出当前循环，`continue` 跳过本轮剩余部分。过度使用会让控制流难以推断。
