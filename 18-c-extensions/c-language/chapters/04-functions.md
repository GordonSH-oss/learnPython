# 04 函数与作用域

## 学习目标

通过函数分解问题，理解声明、定义、值传递、局部变量和静态存储期。

## 函数契约

```c
double average(const int values[], size_t length);
```

声明说明函数名、参数和返回类型；定义提供函数体。调用者应知道输入要求、结果含义和失败方式。

C 默认按值传递。函数接收参数值的副本，修改副本不会改变调用者变量。要修改调用者状态，需要传入地址，这正是指针的重要用途。

## 作用域与生命周期

- 块作用域变量只在花括号内可见。
- 文件作用域名称从声明处到文件末尾可见。
- 普通局部变量进入块时创建，离开块时失效。
- `static` 局部变量会在多次调用之间保留值。

全局可变状态使函数依赖隐藏上下文，应尽量少用。函数最好输入明确、输出明确、副作用有限。

## 递归

递归函数必须有基本情况，并让每次调用更接近基本情况。递归调用会占用调用栈；简单遍历往往使用循环更直接。

## 动手练习

为整数数组实现 `min`、`max` 和 `mean` 函数。空数组不能产生有效最小值，考虑用返回状态和输出参数表达失败。
