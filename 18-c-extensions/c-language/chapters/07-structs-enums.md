# 07 结构体、枚举与联合

## 学习目标

用自定义类型表达领域数据，并理解布局、成员访问和标签状态。

```c
typedef struct {
    char name[40];
    int score;
} Student;
```

对象使用 `student.score`，结构体指针使用 `student_ptr->score`。结构体按值赋值会复制所有成员；大型结构体通常传 `const Student *` 避免复制并表达只读。

## 枚举

枚举为一组整数常量命名：

```c
typedef enum { STATUS_OK, STATUS_INVALID, STATUS_IO_ERROR } Status;
```

它比散落的数字更能表达状态空间，但 C 编译器不会阻止把其他整数赋给枚举变量。

## 联合与标签

联合的成员共享同一块内存，一次只有一个成员的值有效。通常配合枚举记录当前有效成员，这称为带标签联合。忘记标签会用错误类型解释相同字节。

## 内存对齐

结构体大小可能大于成员大小之和，因为编译器会插入填充以满足对齐。成员顺序可能影响大小，但不要为了省几个字节牺牲清晰的数据模型，除非测量证明必要。
