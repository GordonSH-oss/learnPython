# 09 文件与错误处理

## 学习目标

安全打开、读取和关闭文件，并设计调用者能够处理的失败路径。

```c
FILE *file = fopen(path, "r");
if (file == NULL) {
    perror(path);
    return 1;
}
```

文本读取常用 `fgets` 和 `fscanf`，二进制读写常用 `fread` 和 `fwrite`。完成后检查 `fclose`，写入时关闭也可能因磁盘错误而失败。

## 错误模型

C 没有标准异常机制。常见设计包括：

- 返回 `bool` 表示成功，并通过输出参数返回结果。
- 返回枚举错误码区分无效输入、内存不足和 I/O 错误。
- 返回指针，使用 `NULL` 表示失败。
- 标准库函数设置 `errno`，通过 `perror` 或 `strerror` 转成人类可读信息。

不要只打印错误后继续运行。应在最了解恢复策略的层处理错误，其余层返回足够信息。

## 资源清理

函数有多个失败点时，确保每条路径都释放已获得资源。小函数、单一清理区和明确所有权能降低遗漏概率。
