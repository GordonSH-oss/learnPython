# 11 数据结构与函数指针

## 学习目标

实现链表，比较连续存储与节点存储，并使用函数指针传递行为。

链表节点通常同时包含值和下一个节点地址：

```c
typedef struct Node {
    int value;
    struct Node *next;
} Node;
```

插入头部是常数时间，但随机访问是线性时间。动态数组随机访问快、缓存局部性好，通常是默认选择；链表只在节点插入删除模式确实合适时使用。

释放链表时必须先保存下一个节点，再释放当前节点，否则会从已释放内存读取 `next`。

## 函数指针

```c
typedef bool (*Predicate)(int value);
```

函数指针让算法接收行为，例如“统计满足某条件的元素”。标准库 `qsort` 也通过比较函数实现通用排序。回调必须遵守约定的参数和返回语义。

## 复杂度意识

学习 C 不只是在语法层操作内存。选择数据结构时应说明操作复杂度、分配次数、缓存局部性、所有权和失败路径。
