# 02 类型、变量与运算

## 学习目标

选择合适的基本类型，理解整数除法、转换、溢出风险和 `printf` 格式说明符。

## 类型决定数据的解释方式

常用类型包括 `char`、`int`、`long`、`float`、`double` 和 `_Bool`。`sizeof` 返回一个对象或类型占用的字节数，结果类型是 `size_t`。

```c
int count = 3;
double price = 12.5;
double total = count * price;
```

整数除法会舍弃小数部分：`5 / 2` 是 `2`。只要一侧是浮点数，`5.0 / 2` 才是 `2.5`。显式转换 `(double)a / b` 可以表达你的意图。

## 常用运算符

- 算术：`+ - * / %`
- 比较：`== != < <= > >=`
- 逻辑：`&& || !`
- 赋值：`= += -= *= /=`
- 自增与自减：`++ --`

避免在复杂表达式中多次修改同一变量。可读性比少写一行重要。

## 输入与格式

`printf` 常用格式：`%d` 对应 `int`，`%zu` 对应 `size_t`，`%f` 对应 `double`，`%c` 对应字符，`%s` 对应字符串。格式与参数类型不匹配会产生未定义行为。

读取输入时检查返回值：

```c
double value;
if (scanf("%lf", &value) != 1) {
    fprintf(stderr, "输入不是有效数字\n");
    return 1;
}
```

`&value` 是变量地址，第 06 章会解释。
